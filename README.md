# Millonoel Rodriguez — Portfolio

Personal portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Sora. The landing page presents Millonoel’s software engineering work, client websites, experience, toolkit, and contact details.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```

The résumé is available at `/resume.pdf`. The contact form opens a prefilled email in the visitor’s mail app; it does not require a backend service.
